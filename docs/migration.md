# 项目变更与保留范围

原始来源和文件哈希记录在 `migration_manifest.json`。`files` 列出当前保留文件；修改过的源文件保留 `source_sha256`、`source_bytes`；`removed_files` 保存已移除原始文件的来源信息。

## 2026-11-07：移除运动与抓取代码

按用户要求，当前版本移除以下内容：

- Python 机械臂运动封装、夹爪控制、抓放任务、导航封装、执行入口和单次抓取示例。
- C++ 抓取规划、动作执行器、抓放状态机、机器人控制端口、模拟机器人和运动相关类型。
- 机械臂、夹爪、抓取偏移、导航路点和任务重试配置。
- 对应的规划基准、原算法对照生成工具、规划数据集和动作流程测试。

保留 YOLO11n 分割权重、物体 CAD/纹理、Python 视觉感知、相机读取、日志和纯坐标变换；C++ CLI 改为有限帧的感知结果回放。

Python 感知候选选择改为检测置信度优先，去掉机械臂侧别和抓取点可视化。它输出物体位置、姿态及观测宽度，不生成抓取轨迹。未执行模型推理或机器人实测。

## 验证范围

- C++ 几何、感知配置和回放解析测试。
- CLI 逐帧数据保真、故障帧处理及拒绝旧运动参数的检查。
- Python 感知配置在不加载设备 SDK 的环境中读取。
- 当前保留源码/资源的哈希与删除记录检查。
- 干净安装目录中的消费项目编译与链接。

先前的抓取规划性能数字和 200 组规划对照不再描述当前项目，相关实现、数据和复现入口已一并移除。旧版本仍可通过 Git 历史追溯。

## 2026-11-07：移除 YOLO26

此前已移除 `yolo26s-seg_finetuned.pt`（23,353,255 字节），默认模型改为保留的 `yolo11n-seg_finetuned.pt`。移除记录保留在迁移清单中。
